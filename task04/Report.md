# Звіт про аналіз бінарного файлу (Host)

## 1. Розміри секцій пам'яті (size)
```text
   text	   data	    bss	    dec	    hex	filename
   3620	    672	     16	   4308	   10d4	sysinfo_host
```

## 2. Динамічні залежності (ldd)
```text
	linux-vdso.so.1 (0x00007f13b612a000)
	libc.so.6 => /usr/lib/libc.so.6 (0x00007f13b5e00000)
	/lib64/ld-linux-x86-64.so.2 => /usr/lib64/ld-linux-x86-64.so.2 (0x00007f13b612c000)
```
